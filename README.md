 # AI-Based Student Performance Prediction

## Week 2: Designing an AI Model Architecture

### Project Overview
This project explores the use of Artificial Intelligence and Machine Learning to predict student academic performance.

### Objective
To design a suitable machine learning model architecture that can estimate student performance using relevant educational factors.

### Problem Statement
Student performance can be influenced by factors such as study hours, attendance, and previous academic marks. This project explores how these factors can be used to estimate academic outcomes.

### Proposed Model Architecture
1. Input Data: Student study hours, attendance, and previous marks.
2. Data Preprocessing: Clean and prepare the input data.
3. Feature Selection: Select relevant student performance factors.
4. Machine Learning Model: Use a suitable prediction algorithm.
5. Output: Predicted student performance.

### Technologies
- Python
- Machine Learning
- Scikit-learn
- Data Preprocessing

### Week 2 Activities
- Designed the proposed AI model architecture.
- Identified input features and expected output.
- Selected a suitable machine learning approach.
- Documented model design choices.
